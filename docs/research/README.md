# Research briefs

One file per person, from Day 3 of [`docs/WEEK_PLAN.md`](../WEEK_PLAN.md):

- `reia.md` — matching & detection literature: what illumination-invariant matching actually exists, and what's been validated on real planetary imagery vs. terrestrial/synthetic benchmarks only
- `riddhi.md` — how USGS/ISIS3 and ISRO actually generate tie points and run bundle adjustment operationally, and what accuracy their published products claim
- `mehak.md` — why cross-mission automatic registration hasn't been deployed at scale: downlink, calibration, format, and interagency barriers, with documented failure cases
- `manya.md` — alternatives and complements to feature matching: photometric normalization, shape-from-shading, photoclinometry, learned relighting

Each brief: bullet notes, 3–6 real cited sources, and a short "what this means for LunarMatch" section tying the literature back to this codebase's actual results.
